# Voice notes folder

Upload your own voice recordings here. The bot sends them after its text message.
File name = what it is for (extension can be .opus, .ogg, .m4a, .aac or .mp3):

| File name | When the bot sends it |
|---|---|
| welcome | after the greeting (hi / hello / salam) |
| menu | after the menu |
| help | after "help" |
| type | when asking 1 = pickup, 2 = delivery (optional) |
| name | when asking for name (optional) |
| address | when asking for name + address (optional) |
| confirm | when asking 1 = confirm, 2 = cancel (optional) |
| done | after the order is placed (optional) |

Missing file = that voice is simply skipped. Keep each clip short (under 1 minute).
